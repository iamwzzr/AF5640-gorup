# 产品介绍页设计

## 方向

把 DistributionCheck 介绍成可理解、可试用的软件。默认打开介绍页，网站导航依次为「项目介绍」「收益核对」。介绍连续滚动，核对工具继续保留输入与结果。

```
品牌              项目介绍 / 收益核对                 语言
                     产品的一句话价值
                       主要行动入口
                    大幅可交互软件预览
总额与个人差额 → 查回原始行 → 使用者 → 100人样本 → 项目详情 / 试用
```

- 色彩：纸白 `#ffffff`、浅灰 `#f5f5f7`、石墨 `#1d1d1f`、次要文字 `#626269`、行动蓝 `#0071e3`、确认绿 `#187448`。深色仅用于解释「总额不能说明每个人都收齐」的段落。
- 字体：系统无衬线字体，macOS 优先使用平台字体，中文使用 PingFang SC。大标题收紧字距，正文保持舒适行高；中英文分别控制换行。
- 布局：通栏背景，正文最大 1120px。首屏居中，后续标题与解释左对齐。软件预览作为主视觉，减少相同大小卡片、状态标签和专业名词。
- 全局顶栏：两页使用相同结构、对齐和导航字重，切换时仅改变选中标记；示例开关放在核对工具的步骤区域，工具入口保留在网站导航及介绍正文中。
- 图片：实际软件截图用于说明查回原始记录；已有插画用于说明工作场景。所有金额来自程序生成的合成证据，截图和插画明确标注用途。
- 交互：原生滚动、锚点导航、可选择的收款人和问题、可展开的项目细节。用户操作立即反馈；无自动轮播或强制滚动，尊重减少动态效果与降低透明度偏好。
- 内容：先讲用途和结果，商业设想、竞争产品、参赛方向和来源放到下方。潜在客户、价格和节时效果仍标为待验证。

## 参考及适用范围

- [ADDX 官网](https://www.addx.co/en/)：一句话价值、大幅产品画面、按使用者需要展开、持续可见的行动入口。
- [2022 年奖项公开结果](https://tadsawards.org/past-results/tads-awards-2022/)：ADDX 为该届获奖项目。参考的是现今可访问的公开产品网站，未取得其 2022 年完整参赛界面，不将当前页面描述为历史原版。
- [Apple macOS 产品页](https://www.apple.com/os/macos/)：标题层级、留白、产品细节画面、连续浏览的段落节奏。仅借鉴表现方法，不使用 Apple 品牌资产。
- [apple-design 技能](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md)：平台字体、字号对应字距、轻薄导航、按下反馈及辅助使用偏好。通过公开技能文件读取应用，未新增动画依赖。
- 已有 `frontend-design` 与 `ui-ux-pro-max`：设计系统查询支持低密度布局与克制动效；查询中的时尚衬线字体和金色配色不适合本产品，因此采用上述系统字体与行动蓝。

## 实现前复核

首屏以软件画面取代叙事人物介绍；信息按用户理解顺序展开。差额、原始行号和可运行工具是本项目的具体内容，不添加客户标志、采用数量或收益率作为装饰性证明。

## 课程范围调整

按已提供的老师要求，访谈3–5个团队、计时对比和采购意愿调查没有被列为必做项。依用户要求，页面已移除这项额外建议及其相关承诺，最后一段改为「关于这个工具」，保留当前功能、商业设想和资料依据。
